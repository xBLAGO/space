# BLAGO — публичный исследовательский срез

Публикация фиксирует исходники и инженерные результаты UEL 0.3 вместе со ссылками на предшествующие Foundation. Срез имеет статус research prerelease. GO относится к изолированным синтетическим испытаниям. Реальные участники остаются NO-GO до независимой проверки и закрытия прежних release gates.

Архив содержит десять явно перечисленных файлов — индекс, снимок публичных PR, документы UEL 0.3, синтетические evidence/vectors, manifest и SHA256SUMS. Полный код остаётся доступен по точному GitHub commit. Исходные файлы извлекаются через git show, поэтому несохранённые и untracked-файлы рабочего каталога не участвуют.

Две локальные сборки архива побайтово совпали. Опубликованные файлы были скачаны с GitHub и HF и сравнены с локальной сборкой. Общий SHA-256 — `35a6d11dbb49ed91bb2d74b58f6d50d714f000fc3363f27e8013d4386dff568e`. Размер — 26084 байта. Результат публикации сохранён в [PUBLICATION_RECEIPT.json](PUBLICATION_RECEIPT.json).

## Воспроизведение архива

```sh
python3 docs/publication/build_snapshot.py --output /tmp/blago-publication-new-copy
```

Output должен быть новым каталогом. Script использует фиксированный source commit и сохранённые метаданные. Перечень файлов ограничен константой FILES. Дополнительно проверяются признаки токенов и приватных ключей. Публикация фактических журналов, SQLite, credentials и персональных диалогов исключена составом архива.

## Сайт и следующие решения

Репозиторий сайта найден в xBLAGO/web2, его CNAME — xblago.space. Три главные страницы получили по одной ссылке на исследовательский архив в отдельной ветке. HTMLParser подтвердил ссылки; удаление добавленной строки воспроизводит исходный файл. Draft PR ожидает решения владельца о слиянии и выпуске сайта.

Действующие тексты сайта отражают прежнюю концепцию проекта и требуют отдельной актуализации относительно предоставленного White Paper 0.1. В текущем PR сайта предложена ссылка на проверяемый срез разработки. Редакция White Paper от 10 ноября здесь используется как концептуальный контекст; её полный текст в этот архив не включён.

HF dataset выбран как архив инженерных документов и синтетических доказательств с публичной web-страницей. Этот формат не запускает runtime приложения. Рабочий HF Space и пользовательские данные остаются отдельной системой. Независимые операторы, внешний security audit и готовность реального пилота этой публикацией не подтверждаются.
