# C12: значение и происхождение — разные состояния

Исходный HEAD: `9fe62d6df06a4b1d390434842bd107b7bdeb72c8`.
Исправленный runtime: `be2402bc97e92dda62b113ce73f14841ff86937b`.
Только синтетический стенд; реальные участники и пилот — **NO-GO**.

`finish_reason=stop` недостаточно: после него работают проверка соединения
продолжения и финальные ограничения текста. Промежуточные тексты и конкретная
причина отклонения в данном отчёте отсутствуют. Ни отсутствие overlap, ни другой
конкретный критерий не объявляются доказанной причиной. Исправление C12 не
является исправлением общего механизма продолжения генерации.

## Исправление

Для узких русскоязычных вопросов «Откуда ... знаешь ... имя/город» применяется
read-only доменная операция `agent_context.provenance_reply`, а не догадка LLM.
Она получает только scoped snapshot текущего участника:

1. Значение и проверяемый источник доступны: назвать сохранённое значение и
   процитировать точный фрагмент исходной пользовательской реплики.
2. Значение доступно, источник UNKNOWN: назвать значение и прямо сказать,
   что исходная реплика недоступна, происхождение записи неизвестно.
3. Значение отсутствует или есть неоднозначность имени: сообщить об отсутствии
   доступных сведений; не утверждать, что человек никогда их не сообщал.

Цитируется только проверенный span значения («Алина», «Перми»), а не вся реплика:
она могла содержать другой факт, который уже удалён. Ссылка объясняет
происхождение заявления, не доказывает истинность имени или города.
Произвольные вопросы об источниках и другие языки пока не охвачены.

Ответ записывается обычным `_record_and_return` и существующим Generation.commit:
сравнение revision/epoch и запись истории остаются в одной транзакции. Удаление
между подготовкой и commit отклоняет ответ. Новых таблиц, миграций, checksum,
полномочий и сетевых вызовов нет. Feature flag и synthetic-only guards сохранены.

Live harness перед городским C12 проверяет **и** сохранённое значение **и**
валидированный source pointer. При неудаче он фиксирует NOT EXECUTED,
SETUP FAILED, ноль запросов для этой проверки, а не ложный PASS.

## Воспроизводимая локальная проверка

В рабочей копии с настроенным безопасным Python/SQLite из RUNBOOK:

```sh
PYTHONPATH=.:src python -m unittest tests.test_agent_context tests.test_agent_context_live_check -v
```

Новые тесты проверяют текст ответа на одном имени до очистки истории, после неё
и после удаления имени; точный фрагмент города; конфликт удаления перед commit;
неуспешную подготовку городского сценария. Полный regression включает прежние
G09 multi-process, crash/replay и recovery tests.

Целевой набор: **35/35 PASS, 79.007 s**, без HF-запросов. Проверка source/schema/
migration manifest — PASS. Дополнительно три новых теста C12 отдельно прошли
за 3.403 s. Первый расширенный запуск в sandbox имел единственную ошибку на
запрещённом bind локального HTTP-сервера; это не считается успешным полным
регрессом. Ошибка подготовки harness (`blago_tag` на обычном соединении)
выявлена тестами и исправлена использованием штатного защищённого transaction API.
Запущенный до этой коррекции расширенный прогон завершился: 540 тестов,
476.253 s, две ошибки — оба harness-теста на `blago_tag`; они повторно прошли
в итоговом наборе 35/35. Это промежуточный FAIL, не полный локальный PASS.
Полный regression исправленного exact SHA выполняется в
[PR CI](https://github.com/xBLAGO/space/actions/runs/44717132654) и
[push CI](https://github.com/xBLAGO/space/actions/runs/44717120391);
их фактическое завершение проверяется отдельно, а не выводится из этого текста.

Проверяемые ответы одного и того же синтетического участника:

| Состояние | Ответ |
|---|---|
| Имя и источник доступны | В памяти сохранено: имя — Алина. Источник — твоё сообщение; точный фрагмент: «Алина». |
| После очистки истории, имя осталось | В памяти сохранилось: имя — Алина. Исходная реплика сейчас недоступна; происхождение записи неизвестно. |
| После удаления имени | Сейчас в доступной памяти нет этих сведений. |

Живой повтор исправленной версии, физические Android/iPhone, живой переход
Web → Bot → Mini App пока **NOT EXECUTED**. C02 — произвольная старая тема
недоступна; C12 legacy source остаётся UNKNOWN; C14 — отдельная федерация.
Успех детерминированного C12 не квалифицирует общее качество живой модели.
