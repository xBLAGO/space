# Threat model: приватный контекст

## Границы доверия

Авторизацию определяют существующие IdentityRuntime / server session / проверенная Telegram-привязка. Профиль, память, история и ответы LLM не выдают полномочий. Существующие SQLite, privacy journal и независимый witness должны пройти свои проверки. Администратор с ключом журнала не становится независимым проверяющим.

## Атаки и controls

| Угроза | Control / проверка | Остаток |
|---|---|---|
| Подмена UID / чужой source ID | Сессия сверяется внутри snapshot и commit; SQL source lookup включает owner и role | Доверенные внутренние методы по UID не являются публичным API |
| Удаление во время LLM | Прежние revision/epoch + atomic CAS, повтор G09 в новом режиме | Уже переданный провайдеру текст невозможно отозвать |
| Возврат удалённого через обычную историю | Retained history floor; исправление исключает и свою пару | Консервативная потеря предыдущего сырого контекста |
| Возврат через source quote другого факта | Только минимальный value span, не целая исходная реплика | Самостоятельный разрешённый факт может содержать связанное значение; удаление одного ключа не равно стиранию всех упоминаний во всех независимых категориях |
| Профиль повторно сообщает забытое имя | Retained address DENY; новый owner update привязан к HMAC точного выбранного значения | Настройка профиля сохраняется для владельца; запрет относится к LLM-раскрытию |
| Старая SQLite и повтор ID | Независимая граница + replay AUTOINCREMENT, explicit migration | Полная потеря control plane → отказ / ручная процедура, не успешное восстановление |
| Сбой между memory и history | Одна транзакция, source marker превращается в ID только при atomic pair | Write-ahead denial при неопределённом commit может снизить доступность |
| Prompt injection из памяти | JSON-данные, системное разграничение, модель не получает инструментов изменения identity/Help | Нельзя доказать послушание произвольной модели unit-тестами |
| Гипотеза / цитата / third party как owner fact | Whole-message veto и отрицательные guards, узкое clause extraction, grounded value | Неподдерживаемые грамматические формы пропускаются, не угадываются |
| Ложное `confirmed` / confidence | Явно SELF_DECLARED; независимой проверки нет | Изменение старой truth taxonomy потребует отдельной совместимой миграции |
| Утечка диагностикой | В журнале HMAC-теги, числовая граница и permission state; source quote не дублируется в БД / логах | Evidence стенда содержит только синтетические реплики |

Новые публичные endpoint, переносимый auth bundle, внешняя публикация в ISTINA, embeddings и LLM-summary не вводятся. Модель сама не публикует Help и не меняет аудиторию. Help lifecycle, consent, deletion, retention и recovery guards остаются каноническими.

## Обязательные дальнейшие проверки

Живая модель на разрешённом тестовом токене; человеческая рубрика factuality и обращений; физические WebView; поведение при большом retained журнале; независимый security review. Same-author тесты не называются независимым аудитом. До этого реальные участники — NO-GO.
