# Data Lifecycle Matrix — proposed synthetic policy

Версия `synthetic-lifecycle-1`, runtime `9abb7cc7b22346be0a9b095e7f13b1dc81928e28`. **NOT APPROVED FOR REAL USERS.** В таблице «основание» означает техническое назначение и ожидаемый выбор участника, а не утверждённое правовое основание. Оператор будущего пилота должен утвердить основания, сроки, роли и обработку прав до допуска людей.

Инвентаризация [inventory.json](inventory.json) получена только из **новой** SQLite: 56 таблиц, поля и FK без содержимого. Группировка ниже покрывает все таблицы; набор автоматически отклоняет неизвестную таблицу. «Владелец» — субъект данных / ответственный за механизм, а не право оператора распоряжаться ими.

TTL означает eligibility для explicit `sweep`, **не обещание удаления ровно в эту секунду**. До выполнения sweep нет дополнительного read-time expiry. Auth проверяет свои expiry независимо. Свежие данные и подтверждённая активная память автоматически не удаляются. Любой restore требует оригинальных controls, replay denials и смену context epoch; если свежесть controls недоказуема, обслуживание запрещено.

## Основания решения G04

Локальные тесты доказывают **логическое** удаление в объявленном scope при сохранённых controls. Они не определяют срок закона, физическое стирание, время запуска scheduler, downstream deletion, независимость custodian или невозможность корреляции метаданных. Поэтому G04 остаётся UNKNOWN. Перед PASS обязательны утверждённая полная matrix, выполненные операторские SLA/restore drills, учёт всех copies, provider obligations, независимая privacy review и проверенный путь для legacy blockers.
