# Threat model — capital091 delta

| Угроза | Контроль | Ограничение |
|---|---|---|
| IDOR / подмена actor | Fresh active session и приватная membership, key_id связывается с UID | Тестовые аккаунты не доказывают уникальность человека |
| Forged receipts | Отдельный pinned Ed25519 evidence key, точные поля и domain separation | Fixture oracle является доверенным источником стенда, не банком и не независимой проверкой |
| Повтор / двойной расход | CAS и idempotency в одной SQLite write transaction, потребление approval и evidence | Отдельные базы не координируют общий фонд |
| Self approval | Автор, согласующий и исполнитель разделены на переходах | Сговор и скрытое владение несколькими аккаунтами остаются |
| Просрочка и отзыв | Expiry команд, ключей и точного предложения, signed revoke и CAS | Просроченный резерв сам не становится свободным. Для освобождения нужен действующий уполномоченный участник |
| Clock rollback | Время версии не может быть меньше предыдущего | Доверие к часам узла сохраняется, rollback между перезапусками без нового события не равен независимому времени |
| Частичная запись | Source, проекция и UEL intent в одной транзакции | Сбой после внешнего journal до commit закрывает фонд вместо восстановления положительных grants |
| Старый snapshot / control loss | Existing journal/witness/live custody, capital_state hold, UEL retirement | Вся история после недоказанного restore не считается восстановленным капиталом |
| Утечка истории | Только private member audit, минимальный own export, payload не публикуется | Получатель экспортированной копии может сохранить её. Псевдонимы и суммы могут повторно идентифицировать |
| Удаление участника | Полное удаление затронутого синтетического фонда, retained hold | Возможна потеря доступности другим участникам. Для реального фонда необходима коллективно утверждённая политика |
| Компрометация сервера | Подписи и отдельно закреплённый audit frontier дают возможность последующей проверки | Runtime доверяет собственному HMAC/control plane. Полностью скомпрометированный сервер не становится безопасным от наличия подписей |
| DoS | Ограничены funds, members, lots, proposals, version count и command size | Реальные SLO и нагрузка не установлены |
| Смешение Help и капитала | CAPITAL — отдельный домен, общий UEL, нет source writes в Help/Asset | Расход не доказывает удовлетворение потребности |

Независимый оператор, внешняя ревизия, реальные устройства, живой HF и эксплуатация с реальными людьми — NOT EXECUTED. Прежние release gates не повышаются.
