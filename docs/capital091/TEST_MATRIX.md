# Испытания capital091

Все сценарии синтетические. Ожидаемый результат, соответствующий test method и фактический статус сохраняются в machine-readable evidence после прогона.

| Сценарий | Ожидаемый результат | Проверка |
|---|---|---|
| Непроверенное поступление / ложная квитанция | Доступный капитал не увеличивается | неподтверждённое_поступление, ложная_подпись, подмена_суммы |
| Полный расход и частичный возврат | Копейки сходятся, refund не выше spend | полный_цикл, нельзя_отменой_создать_возврат |
| Резерв частей нескольких lots | Применяется вместе и в пределах approval | частичный_резерв_нескольких_источников |
| Два конкурентных резерва | Только один CAS проходит | два_процесса_не_резервируют_дважды |
| Три повтора одного резерва | Один source event, три одинаковые квитанции | три_процесса_повторяют_один_резерв |
| Revoke versus spend | Один сериализованный исход | отзыв_и_расход_сериализованы |
| Повтор подтверждения расхода | Первоначальная квитанция, без нового расхода | повтор_расхода_не_тратит_дважды |
| Key/policy/actor substitution | Отказ без изменения состояния | подмена_политики, подмена_участника, отозванный_ключ |
| Истечение срока | Новая операция запрещена | истёкшее_полномочие, истечение_согласования |
| Сбой после изменения проекции | Полный rollback | ошибка_проекции_откатывает_операцию |
| Crash до journal / после journal / после commit | Rollback / hold / прежняя квитанция | crash_* |
| Перезапуск и source tampering | Состояние сохраняется / fail-closed | перезапуск, повреждение_источника |
| Миграция, повтор и DDL fault | Старые записи и checksums неизменны, rollback | MigrationTests |
| Erasure и старый backup | Нет возвращённого payload/полномочий | удаление_и_старый_backup, удаление_аккаунта |
| Export isolation | Только собственная membership, без tokens | экспорт_не_раскрывает_чужие_привязки |
| Custody loss / index repair | Закрытие / прежний source без нового grant | потеря_внешнего_checkpoint, ремонт_индекса |
| Offline verifier / truncation | Равный баланс / отказ | независимый_запуск_верификатора_и_подмена |
| 100 участников / 10M RUB | 703M spent + 50M reserve + 247M available minor units | tools.capital_lab |
| Regression | Прежние 684 теста, frozen 72 vectors и CI Docker/browser | Full CI |

Независимый implementation/audit и отдельный независимый оператор не выполнены. Проверка нескольких процессов на одном компьютере относится к local integration. Нет evidence реального поступления или траты денег.
