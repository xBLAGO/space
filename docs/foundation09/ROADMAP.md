# Путь к действительной коллективной экономике

| Этап | Результат | Gate |
|---|---|---|
| Этот PR — Collective Balance 01 | Принципы, пять read-only views, disposable planning, 100-person / 10M RUB сценарий | GO isolated synthetic при успешных проверках |
| Durable Capital Design | Ратифицируемые правила, currency/rights/evidence model, exact consent, новая UEL версия | Design/security review, никаких неподтверждённых grants |
| Durable synthetic capital | Canonical lots, constraints, reserve CAS, approvals, source outbox в существующий UEL | Multiworker, crash/rollback/replay, retained denials и independent checkpoint proof |
| Project/capability domain | Структурированные количества, расписание, dependencies, milestone criteria, добровольные rights | Без второго Help lifecycle и повторного stock count |
| Independent operation | Отдельный оператор, отдельный rollback domain и проверка receipts/mandates | Независимое испытание, не same-author audit |
| Real nonfinancial MVP | Устройства, реальные безопасные пользовательские сценарии, HF качество, G02–G11 | Решение владельца, реальный пилот до этого NO-GO |
| Real common resources | Коллективные правила, appeal, custody, retention, legal responsibilities | Отдельное общественное и инженерное решение |

В следующем PR не следует автоматически подключать банки или Sovereign Identity. Следующий конкретный результат — проверенный контракт durable approvals/reservations в существующем UEL. Процентные доли фонда, закупочные приоритеты и правила общественного имущества утверждаются отдельно.
